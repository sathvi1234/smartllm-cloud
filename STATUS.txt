TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────────────

Issue: "Cannot connect to backend"
  Solution: Verify backend running on 8000
  Command: curl http://localhost:8000/health

Issue: "CORS error"
  Solution: Check NEXT_PUBLIC_API_URL in app/.env.local
  Should be: http://localhost:8000/api

Issue: "Login fails"
  Solution: Check browser console for error
  Try: demo@smartllm.ai / demo123
  Backend logs should show error details

Issue: "Database locked"
  Solution: Close all servers, delete backend/smartllm.db
  Restart with ./start.sh

Issue: "Port already in use"
  Solution: Check what's using port 3000/8000
  Kill existing process: lsof -ti:3000 | xargs kill -9

See INTEGRATION_TEST.md for more troubleshooting.
